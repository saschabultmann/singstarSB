# 🎤 SingStar Party

Karaoke party game: the TV browser shows synced lyrics, live pitch lines and scores; phones are the microphones; music comes from Spotify (Connect).

- TV: `docs/tv.html` · Mic: `docs/mic.html` · iOS app: `app/` (Expo, WebView wrapper with native mic permission)
- Setup (works entirely from a phone): see **[SETUP.md](SETUP.md)**
